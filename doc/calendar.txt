INTRODUCTION                                    *calendar*

This script creates a calendar window in vim.

It is a forked and refactored version for Vim 9.0 of vim-calendar originally
written by Yasuhiro Matsumoto <mattn.jp@gmail.com>

You can create your own diaries and link them to the calendar.
It does not rely on any external program, such as cal, etc.

It requires Vim 9.0.

==============================================================================
COMMANDS                                        *calendar-commands*

vim-calendar makes the following commands available:

                                                *calendar-:Calendar*
:Calendar [year, [month]] Show calendar at this year and this month. Window
                           position is controlled by
                           |g:calendar_config.position|.
                           - no arguments: current year/current month
                           - one argument: year (current month)
                           - two arguments: year and month

                                            *calendar-:CalendarSearch*
:CalendarSearch [keyword, [year]]

                            Search keyword in current calendar diary book.
                            If year is passed, it limits the search
                            to that specific year.

==============================================================================
MAPPINGS                                        *calendar-mappings*

h/j/k/l          move cursor
|<Up>|             previous month,
|<Down>|           next month,
|<Left>|           previous year,
|<Right>|          next year,
t                go to today,
|<CR>|             open/switch on cursor,
|<Tab>| / |<S-Tab>|  next/prev diary,
q or |<Esc>|       close,

CONFIGURATION                                        *calendar-configuration*

                                                *g:calendar_config*
Calendar options are configured through one dictionary: >
  g:calendar_config = {
        position: 'left',
        cal_type: 'eu',
        show_week_number: false,
        number_of_months: 3,
        holidays: {'2025-12-25': 'Christmas'},
        search_grep: 'internal',
        action: 'OpenDiaryPage',
        auto_create_diary_dirs: false,
        diaries_dict: {My_Diary: {path: '~/my_diary', resolution: 'day'}},
        active_diary: 'My_Diary',
      }
<

Supported keys in |g:calendar_config|:

                 position       Calendar position.
                                Allowed values: 'left', 'right', 'popup'
                                Default: 'left'

                 cal_type       Calendar type:
                                  - 'eu': week start on Monday,
                                  - 'us': week start on Sunday,
                                  - 'work': five week days.
                                Default: 'eu'

            show_week_number    If |true| shows the weekdays.
                                Default: |false|

            number_of_months    Number of months to be displayed.
                                Default: 3

                    holidays    Dictionary to specify holidays.
                                It is keyed by YYYY-MM-DD.
                                Default: {}

              search_grep       Used by |:CalendarSearch|.
                                Can be:
                                  - 'internal' (|:vimgrep|)
                                  - 'external' (|:grep|)
                                Default: 'internal'

                      action    Function name called on <CR>.
                                The function signature shall be:

                                        MyFunc(
                                          day: number,
                                          month: number,
                                          year: number,
                                          week: number
                                        )

                                Default: 'OpenDiaryPage' (internal function)

      auto_create_diary_dirs    When |true|, creates missing diary
                                directories automatically using
                                `mkdir(path, 'p')`.
                                When false, warns and asks the user
                                to create directories manually.
                                Default: |false|

              diaries_dict      Dictionary containing the diaries information.
                                The dictionary is of the form:
                                      dict: {
                                        name: {
                                          path: string,
                                          resolution: 'day' or 'month'
                                          }
                                      }

                                Resolution 'day' means that you can link a
                                markdown file to each day of the calendar;
                                Resolution 'month' means that you can link a
                                markdown file to each month of the calendar.
                                If path is omitted, it defaults to '~/my_diary'.
                                Directory creation follows
                                auto_create_diary_dirs.
                                Default: {My_Diary: {path: '~/my_diary',
                                          resolution: 'day'}}

              active_diary      Diary name present in diaries_dict key
                                Default: ''


==============================================================================
AUTOCOMMANDS                                   *calendar-autocmds*

The plugin triggers one event just before drawing the calendar view: >
  doautocmd User CalendarBeforeShow
